Engineering Project

Thesis Project · 2025
IoT-Based Smart Circuit Breaker
Designed and built an intelligent circuit breaker that monitors real-time electrical current, automatically detects overload and underload conditions, trips a relay to protect connected devices, and streams live data to a web dashboard over Wi-Fi — all using an ESP8266 microcontroller and a current transformer sensor.
ESP8266 Current Transformer Relay Module Arduino IDE Proteus IoT Web Dashboard AC & Solar Power
Result: Tested across 3 sessions at University of Ilorin using both AC and solar power. System accurately detected underload, normal, and overload conditions in real-time and successfully streamed all data to a web application — validating full IoT functionality.
